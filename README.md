# personal-growth-coach

一個俾 AI 用嘅個人成長教練 skill。佢唔係一套勵志口號，亦唔係某個人嘅品牌方法。佢係一套 coaching 思維邏輯：教 AI 點樣諗、點樣問、點樣拆、點樣驗證，最後點樣推用家落一個細到唔使說服自己嘅行動。

## 呢個 skill 教 AI 咩

核心主軸係：**改變靠重複同證據**。語言負責重複，行動負責製造證據。

具體手法包括：

- **分層定位**：先分清問題喺知識、資源定係安全／信念層，再落手，唔喺錯嘅一層用力。
- **比喻系統**：由用家自己嘅世界揀一個比喻，貫穿全程，令抽象嘅痛變得易明易記。
- **假設驗證**：將可能嘅舊信念列成假設，用身體反應驗證，唔係用「腦覺得有道理」驗證。
- **雙重困局**：畫出兩條互相夾死嘅信念，解釋點解人會凍結，再揀容易證偽嗰邊先拆。
- **可驗證新認知**：唔用空泛肯定句。新認知要有重新定義、親身證據同行為規則。
- **拆內在聲音**：固定 4 條問題，問完就停，再分流去「缺知識」或者「限制性信念」。
- **語言微調**：四類可信句式、改一個字、用第三身稱呼自己。
- **能量盤點**：用生活平衡輪量化，最低位先補，之後先加碼。
- **目標 pipeline**：大 → 中 → 細 → 今日 5 分鐘，配合「如果……我就……」執行意圖。
- **指標同停止點**：早期只計行動，唔計用家最驚嘅結果。預設名額同停止點，保住自主感。
- **觸發急救**：標籤 → 時間定位 → 微行動。
- **理論白話化**、**時限書寫**、**間接挖掘真正想要**、**點名分析逃避**、**轉介同返主線**。

## 適合咩場景

- 「我知道點做，但就係做唔到」
- 拖延、自我懷疑、腦入面有把聲話自己唔得
- 想改變但好驚，或者驚失敗之餘又驚成功
- 唔知自己真正想要咩
- 目標太大，唔知點開始
- 讀咗好多、分析咗好耐，但冇行動

## 點用

1. 將 `SKILL.md` 放入你嘅 AI 工具嘅 skills 目錄，或者喺對話開頭貼入成份內容。
2. 用平時講嘢嘅方式開始，例如：「我想轉工轉咗兩年都冇郁」、「我一諗到要公開表達自己就好心慌」。
3. AI 會一次只問一條問題。慢慢答，用自己嘅字眼答就得。
4. 每輪完成之後，AI 會整一張行動卡，入面有你今日嘅第一步同觸發急救流程。
5. 你可以叫佢「講白啲」（唔用術語），或者叫佢「深入啲」（詳細分析）。

## 教練姿態

- 誠實，唔迎合
- 保留用家原字眼，唔幫用家作故事，唔知就留 `[ ]`
- 一次只問一條
- 舊模式點名一次，就轉去行動
- 每次對話以一個具體動作收尾

## 邊界

- **呢個唔係心理治療，亦唔做任何診斷。** AI 會借用心理學框架幫你理解自己，但唔會俾你貼病名或者人格標籤。
- **唔保證結果。** 佢係陪你行動嘅工具，唔係承諾。
- 如果卡住嘅位一再指向深層創傷，或者出現持續嘅情緒困擾，AI 會建議你搵輔導員或者心理專業人士。轉介之後，行動部分可以並行，但教練唔會越界做治療。
- 如果出現自傷或者安全風險，AI 會停低流程，確認你嘅安全，並提供當地危機支援資訊。
- 請唔好輸入身份證號碼、地址等敏感私隱資料。
